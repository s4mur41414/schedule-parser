# Парсер расписания ЭИОС МГУ им. Н. П. Огарёва (в формат ICS)

Скрипт для автоматического получения расписания занятий из электронной информационно-образовательной среды (ЭИОС) Мордовского государственного университета и конвертации его в стандартный формат `.ics` (iCalendar).

Полученный файл можно импортировать в Apple Calendar, Google Calendar, Outlook или любой другой календарь, поддерживающий стандарт iCalendar.

## Особенности

- **Автоматическая авторизация**: Скрипт самостоятельно обрабатывает скрытые поля ASP.NET (`__VIEWSTATE`, `__EVENTVALIDATION`) для успешного входа в систему.
- **Точный расчет недель**: Используется корректная математика тиков .NET (`DateTime.Ticks`) для навигации по календарю ЭИОС без привязки к жестким датам в URL.
- **Умное определение года**: Алгоритм корректно обрабатывает переход между осенним и весенним семестрами (например, расписание в декабре на январь следующего года).
- **Оптимизация для Apple Calendar**: Краткое ФИО преподавателя добавляется в поле «Место» (Location), так как iOS по умолчанию скрывает поле «Описание». Полное ФИО сохраняется в описании для деталей.
- **Дедупликация**: Встроенная защита от добавления одинаковых занятий в календарь при возможных сбоях на стороне сервера ЭИОС.
- **GitHub Actions**: Полная автоматизация. Скрипт запускается по расписанию (каждый день в 05:00 UTC) и обновляет файл в репозитории.

## Требования

- Python 3.12 или выше
- Зависимости: `requests`, `beautifulsoup4`, `lxml`, `ics`

## Установка и настройка

### 1. Клонирование репозитория

git clone https://github.com/s4mur41414/schedule-parser

### 2. Установка зависимостей

pip install -r requirements.txt

### 3. Настройка переменных окружения

Для локального запуска создай файл `.env` (или экспортируй переменные в терминале):
MRS_USERNAME=твой_логин_от_эиос
MRS_PASSWORD=твой_пароль_от_эиос
MRS_GROUP=твоя_учебная_группа
### 4. Локальный запуск

python schedule_to_ical.py

После успешного выполнения в папке появится файл `schedule.ics`.

## Настройка автоматизации (GitHub Actions)

Чтобы расписание обновлялось автоматически без твоего участия:

1. Открой настройки репозитория на GitHub: **Settings** → **Secrets and variables** → **Actions**.
2. Нажми **New repository secret** и добавь три секрета:
    - `MRS_USERNAME`: твой логин от ЭИОС
    - `MRS_PASSWORD`: твой пароль от ЭИОС
    - `MRS_GROUP`: номер твоей группы
3. Убедись, что в репозитории существует файл `.github/workflows/update_schedule.yml` с конфигурацией запуска.

Скрипт будет автоматически запускаться каждый день в 05:00 по UTC, проверять расписание на 4 недели вперед и делать коммит, если найдены изменения.
## Импорт в календарь

- **Apple Calendar (macOS)**: Файл → Импорт → выбери `schedule.ics`.
- **Apple Calendar (iOS)**: Открой файл `schedule.ics` через «Файлы» или отправь себе в Telegram/почту и нажми «Добавить в Календарь».
- **Google Calendar**: Настройки → Импорт и экспорт → Загрузить файл с компьютера.
